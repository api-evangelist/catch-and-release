# Catch&Release

> Catch&Release ("Catch+Release") is a UGC creator platform and content-licensing
> marketplace for brands and agencies. It helps marketing teams discover, clear, and
> license "found content" — real videos and photos made by everyday people and
> creators — for use in advertising campaigns, and it pays creators for the clips it
> licenses from them.

## Machine-access status — read this first

Catch&Release publishes **no public API**. As of 2026-08-12 there is no developer
portal, no API reference, no OpenAPI/AsyncAPI/GraphQL contract, no SDK, no webhook
catalog, no MCP server, and no A2A agent card anywhere on its public surface. A full
crawl of the 415-URL sitemap (https://www.catchandrelease.com/sitemap.xml) returns
zero developer or API pages, and GitHub code search across the company's own
organization returns zero OpenAPI or Swagger files.

The product is used through the web application at https://app.catchandrelease.com,
which sits entirely behind a FusionAuth OAuth login: every path returns HTTP 302 to
https://auth.catchandrelease.com/oauth2/authorize.

The terms of use explicitly prohibit programmatic access: users "agree not to scrape
or otherwise use automated means to access or gather information from the Website."
robots.txt disallows the entire application surface (/dashboard, /collections*,
/offer*, /shots*, /picker, /review, /request-*, /usage-details). An agent should not
attempt to drive this product automatically. Use the human sign-up and the sales
contact below.

## The only machine-readable endpoints

- [Status page JSON — current](https://status.catchandrelease.com/api/v2/status.json): Atlassian Statuspage overall indicator for Catch+Release. HTTP 200, anonymous.
- [Status page JSON — summary](https://status.catchandrelease.com/api/v2/summary.json): Components, open incidents, scheduled maintenances. HTTP 200, anonymous.
- [Status incident history (RSS)](https://status.catchandrelease.com/history.rss): HTTP 200, anonymous.
- [OIDC discovery](https://auth.catchandrelease.com/.well-known/openid-configuration): FusionAuth OpenID Connect discovery for the application login. Not an API authorization surface.
- [JWKS](https://auth.catchandrelease.com/.well-known/jwks.json): Public signing keys for the OIDC issuer.
